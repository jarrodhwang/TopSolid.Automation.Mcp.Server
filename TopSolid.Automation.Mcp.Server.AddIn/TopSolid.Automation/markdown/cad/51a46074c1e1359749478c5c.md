# Method CreatePositioning

#### CreatePositioning(DocumentId)

##### Declaration

```

```

##### Parameters

|  Type |  Name |  Description |

##### Remarks

StartModification(string, bool) and EnsureIsDirty(ref DocumentId) must be called before calling this method.
