# Method GetCollisionsManagement

#### GetCollisionsManagement(DocumentId, out ElementId, out bool, out bool, out bool)

```
[OperationContract]
[AvailableSinceVersion(7, 8, 0, 0)]

```

##### Parameters

|  Type |  Name |  Description |
