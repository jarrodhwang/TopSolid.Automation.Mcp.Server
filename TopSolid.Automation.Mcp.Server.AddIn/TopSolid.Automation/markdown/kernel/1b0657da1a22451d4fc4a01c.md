# Interface IGeometries2D

Gives access to 2D geometric entities.

###### Namespace: TopSolid.Kernel.Automating

###### Assembly: TopSolid.Kernel.Automating.dll

##### Syntax

```
[ServiceContract]
[AvailableSinceVersion(7, 6, 0, 0)]
public interface IGeometries2D
```
