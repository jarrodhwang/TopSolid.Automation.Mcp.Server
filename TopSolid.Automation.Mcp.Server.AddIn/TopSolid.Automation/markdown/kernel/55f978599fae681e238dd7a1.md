# Method GetImporterFileType

#### GetImporterFileType(int, out string, out string[])

Gets the type of files managed by an importer.

##### Declaration

```
[OperationContract]
[AvailableSinceVersion(7, 6, 0, 0)]
void GetImporterFileType(int inImporterIx, out string outFileTypeName, out string[] outFileExtensions)
```

##### Parameters

|  Type |  Name |  Description |  
| --- | --- | --- | 
   
|  int |  inImporterIx |  Index of importer to analyze, within [0, ImporterCount-1].  |  
 
|  string |  outFileTypeName |  Name of the type of the managed files (ex: "Parasolid", for Parasolid files).  |  
 
|  string[] |  outFileExtensions |  Extensions of the managed files, with the leading '.' character (ex: { ".x_t", ".xmt_txt", ".x_b", ".xmt_bin" } for Parasolid files).  |  

##### Remarks

This method is available since v7.6.
