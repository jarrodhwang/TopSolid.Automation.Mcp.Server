# Method CreateBooleanParameter

#### CreateBooleanParameter(DocumentId, bool)

```
[AvailableSinceVersion(7, 6, 301, 40)]
ElementId CreateBooleanParameter(DocumentId inDocumentId, bool inValue)
```

|  Type |  Name |  Description |

|  Type |  Description |
