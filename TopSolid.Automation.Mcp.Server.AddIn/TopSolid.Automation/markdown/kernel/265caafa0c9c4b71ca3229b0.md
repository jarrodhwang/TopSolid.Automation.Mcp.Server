# Method PublishPattern

#### PublishPattern(DocumentId, string, SmartPattern3D)

Creates a pattern publishing entity in a document.

##### Declaration

```
[OperationContract]
[AvailableSinceVersion(7, 20, 400, 180)]
ElementId PublishPattern(DocumentId inDocumentId, string inDescription, SmartPattern3D inDefinition)
```

##### Parameters

|  Type |  Name |  Description |  
| --- | --- | --- | 
   
|  DocumentId |  inDocumentId |  Identifier of the document to modify.  |  
 
|  string |  inDescription |  Publishing description.  |  
 
|  SmartPattern3D |  inDefinition |  Publishing definition.  |  

##### Returns

|  Type |  Description |  
| --- | --- | 
   
|  ElementId |  Identifier of the created publishing entity.  |
