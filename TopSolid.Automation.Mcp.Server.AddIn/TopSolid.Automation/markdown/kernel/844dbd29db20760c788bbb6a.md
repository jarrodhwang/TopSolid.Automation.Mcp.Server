# Method HasDocumentParameterPossibleValues

#### HasDocumentParameterPossibleValues(ElementId)

Tells wether the document parameter has possible values.

##### Declaration

```

```

##### Parameters

|  Type |  Name |  Description |

|  Type |  Description |  
| --- | --- |
