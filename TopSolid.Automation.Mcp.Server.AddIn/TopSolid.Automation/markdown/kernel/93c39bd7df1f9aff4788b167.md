# Method ExportMachineToGlTF

#### ExportMachineToGlTF(DocumentId, string, bool, bool, bool, bool, out string)

Exports a glTF with organized elements.

##### Declaration

```
[OperationContract]
[AvailableSinceVersion(7, 20, 400, 140)]
bool ExportMachineToGlTF(DocumentId inDocumentId, string inFullName, bool inUseGlBFormat, bool inExportSets, bool inExportsLights, bool inExportMaterials, out string outLog)
```

##### Parameters

|  Type |  Name |  Description |  
| --- | --- | --- | 
   
|  DocumentId |  inDocumentId |  the document to export  |  
 
|  string |  inFullName |  the file path  |  
 
|  bool |  inUseGlBFormat |  whether to use glb (true) or glTF (false) format.  |  
 
|  bool |  inExportSets |  true to export sets.  |  
 
|  bool |  inExportsLights |  true to export lights  |  
 
|  bool |  inExportMaterials |  true to export materials  |  
 
|  string |  outLog |  log  |  

##### Returns

|  Type |  Description |  
| --- | --- | 
   
|  bool |  true if export is a success.  |  

##### Remarks

This method must not be called between StartModification(string, bool) and EndModification(bool, bool) methods calls.
 
This method is available since v7.20.
