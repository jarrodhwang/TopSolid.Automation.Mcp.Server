# Method ToInvariantStringValue

#### ToInvariantStringValue(ParameterId)

Gets the text corresponding to the parameter value, without translation.

##### Declaration

```
[OperationContract]
[AvailableSinceVersion(7, 8, 0, 0)]
string ToInvariantStringValue(ParameterId inParameterId)
```

##### Parameters

|  Type |  Name |  Description |  
| --- | --- | --- | 
   
|  ParameterId |  inParameterId |  Identifier of the parameter to analyze.  |  

##### Returns

|  Type |  Description |  
| --- | --- | 
   
|  string |  Text corresponding to the parameter value. The invariant culture is used.  |  

##### Remarks

The numerical values are given in meters and radians without any unit.
