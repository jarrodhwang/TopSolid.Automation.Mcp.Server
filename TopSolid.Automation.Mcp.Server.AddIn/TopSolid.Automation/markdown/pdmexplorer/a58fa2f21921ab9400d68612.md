# Interface IPdm

Gives access to the PDM.

###### Namespace: TopSolid.Pdm.Explorer.Automating

###### Assembly: TopSolid.Pdm.Explorer.Automating.dll

##### Syntax

```
[ServiceContract]
[AvailableSinceVersion(7, 11, 300, 80)]
public interface IPdm
```

##### Remarks

This interface is available since v7.10.

### Properties 

|  Name |  Description |  
| --- | --- | 
   
|   BasicName  |  Gets the name of PDM (i.e. raw name of PDM connection, not localized).  |  
 
|   IsLocal  |  Returns true if current PDM is local  |  
 
|   LibraryProjectsRootFolder  |  Gets the library projects root folder.  |  
 
|   Name  |  Gets the name of PDM (i.e. the localized name of PDM connection).  |  
 
|   Signature  |  Gets the signature of PDM.  |  
 
|   WorkingProjectsRootFolder  |  Gets the working projects root folder.  |
