# Method HasProjectFolderConstituents

#### HasProjectFolderConstituents(PdmProjectFolderId)

Tells whether a project folder has constituents.

##### Declaration

```
[OperationContract]
[AvailableSinceVersion(7, 11, 300, 80)]
bool HasProjectFolderConstituents(PdmProjectFolderId inProjectFolderdId)
```

##### Parameters

|  Type |  Name |  Description |  
| --- | --- | --- | 
   
|  PdmProjectFolderId |  inProjectFolderdId |  Project folder identifier.  |  

##### Returns

|  Type |  Description |  
| --- | --- | 
   
|  bool |  The project folder has constituents, i.e. GetProjectFolderConstituents(PdmProjectFolderId, out List<PdmProjectFolderId>, out List<PdmObjectId>) would not return only empty lists.  |  

##### Remarks

This method is available since v7.10.
