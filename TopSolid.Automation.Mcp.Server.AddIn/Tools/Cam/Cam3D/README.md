# Cam3D

Technology extension area. Existing CAM data is inspected through the sibling Operation, Machine, PartSetup, CuttingConditions, Tooling, NC, Postprocessor and Simulation tools. The public SDK uses shared CAM interfaces; this folder does not imply a separate vendor interface.

No strategy creation or machine execution tool is registered here. Adding one requires a documented operation contract, typed parameters and explicit confirmation/transaction handling appropriate to its actual effect.
